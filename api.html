API options · request lab

Configure the request. Keep the combobox.

Declarative remote selects now accept extra query parameters and a JSON request body as well as headers and credentials. Watch the exact method, URL, headers and payload the plugin builds before you point it at your own API. No wrapper, no hand-written fetch unless you want one.

1. GET — headers and extra query parameters

The select is initialised from its data attributes. Every request carries tenant=north and X-Demo-Client: zidanform-api; typing adds q, paging adds limit and skip. The inspector below is filled from the real fetch() call, not a mock description.

JavaScript equivalent 
zidanSelect('#api-get', {
  mode: 'combobox',
  fetchUrl: 'https://dummyjson.com/products/search',
  fetchItemsPath: 'products',
  fetchTotalPath: 'total',
  fetchSkipParam: 'skip',
  fetchPageSize: 6,
  fetchPageSizeParam: 'limit',
  fetchHeaders: { 'X-Demo-Client': 'zidanform-api' },
  fetchParams: { tenant: 'north' }
});

2. POST — JSON body and static parameters

This endpoint expects a JSON search body. fetchBody is serialised once and sent with Content-Type: application/json; fetchParams adds scope=demo to the URL. The endpoint is a demo-only local mock so this card works offline and deterministically — swap the URL and body for your API and the same options apply. 

the mock waits 300 ms, like a small API

4. The request option reference

Every declarative request option is listed here; the full select options live in the remote select documentation.

OptionData attributeDefaultWhat it does
fetchUrldata-zidan-fetch-urlnullEndpoint that enables declarative fetching.
fetchMethoddata-zidan-fetch-methodGETHTTP method; use POST/PUT/PATCH with a body.
fetchParamsdata-zidan-fetch-paramsnullExtra query parameters merged into every request.
fetchBodydata-zidan-fetch-bodynullJSON-serialisable object/array, or a raw string, sent on non-GET requests.
fetchHeadersdata-zidan-fetch-headersnullExtra request headers, including auth and tenant headers.
fetchCredentialsdata-zidan-fetch-credentialssame-originomit, same-origin or include.
fetchQueryParamdata-zidan-fetch-query-paramqSearch-term parameter; set empty to omit.
fetchPageParamdata-zidan-fetch-page-parampage1-based page number; set empty to omit.
fetchSkipParamdata-zidan-fetch-skip-paramnullSend skip = page × pageSize instead of a page number.
fetchPageSizeParamdata-zidan-fetch-page-size-paramlimitPage-size parameter; set empty to omit.
fetchPageSizedata-zidan-fetch-page-size0Rows per request; enables paging and load-more.
fetchItemsPathdata-zidan-fetch-items-pathnullDot path to the row array, e.g. data.rows.
fetchTotalPathdata-zidan-fetch-total-pathnullDot path to the total count, used for hasMore.
fetchHasMorePathdata-zidan-fetch-has-more-pathnullDot path to a boolean instead of a count.
fetchOptions—nullFull escape hatch: (query, signal, context) => items.
debounce, minChars—250, 0When typing triggers a request.
cacheResults, autoLoadMoredata-zidan-cache-results, data-zidan-auto-load-moretrue, truePage cache and scroll-to-load behaviour.
