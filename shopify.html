A product page your theme could ship today

This page is plain HTML styled like a storefront. In a real theme the same markup lives in a Liquid section, and the three files load through asset_url — no app and no checkout override. (File uploads are the exception: they need an app proxy, covered below.) Shopify does not allow custom scripts on the checkout, so cart, product, contact and newsletter forms are the targets.

Install it in a Shopify theme

      

        Upload the three files to the theme's Assets folder (Online Store → Themes
        → Edit code, or shopify theme push), then reference them in
        layout/theme.liquid. asset_url serves them from Shopify's CDN.
        Place the CSS after the theme's base stylesheet so your overrides still win.
      

      

        

          
1. theme.liquid

          
Add the stylesheets and the script (defer keeps first paint fast).

          

            
            
{{ 'plugin-core.css' | asset_url | stylesheet_tag }}
{{ 'plugin-theme.css' | asset_url | stylesheet_tag }}
<script src="{{ 'zidan-form.js' | asset_url }}" defer></script>

          

        

        

          
2. Product section

          
Liquid renders the variants; ZidanForm only upgrades the control.

          

            
            
<form action="{{ routes.cart_add_url }}" method="post" class="zidan-form">
  <input type="hidden" name="form_type" value="product">
  <input type="hidden" name="utf8" value="✓">

  <select id="variant-select" name="id" class="zidan-select"
          data-zidan-options='{"mode":"combobox"}'>
    {% for variant in product.variants %}
      <option value="{{ variant.id }}"
        {% if variant == product.selected_or_first_available_variant %}selected{% endif %}
        {% unless variant.available %}disabled{% endunless %}>
        {{ variant.title }} — {{ variant.price | money }}
      </option>
    {% endfor %}
  </select>

  <input type="number" name="quantity" value="1" min="1"
         data-zidan="input" data-zidan-stepper="stacked">

  <button type="submit" name="add">Add to cart</button>
</form>

          

        

        

          
3. Theme setting

          
Expose the field theme in the theme editor with a section setting.

          

            
            
{% schema %}
{
  "name": "ZidanForm style",
  "settings": [
    {
      "type": "select",
      "id": "zidan_theme",
      "label": "Field theme",
      "options": [
        {"value": "default", "label": "Default"},
        {"value": "modern", "label": "Modern"},
        {"value": "minimal", "label": "Minimal"},
        {"value": "dark", "label": "Dark"},
        {"value": "glass", "label": "Glass"}
      ],
      "default": "modern"
    }
  ]
}
{% endschema %}

<div data-zidan-theme="{{ section.settings.zidan_theme }}">
  {% comment %} your form markup {% endcomment %}
</div>

          

        

      

    


    

      
What Shopify allows

      
Storefront themes are fully editable; the checkout is not.

      

        

          
Works in theme templates

          
    
            
  • Product forms: variant selects, quantity, line-item properties
    • 
            
  • Contact, newsletter and cart-note forms
    • 
            
  • Dawn-style themes: the real <select> keeps firing change, so price and availability stay in sync
    • 
            
  • Five themes and framework adapters through one data attribute
    • 
          

        

        

          
Not available

          
    
            
  • Checkout — custom scripts are blocked; use Checkout UI Extensions instead
    • 
            
  • Shopify admin — Polaris is the UI kit there
    • 
            
  • File uploads to cart/order — upload through an app proxy, then store the URL in a line-item property or cart attribute
    • 
            
  • Dawn's built-in variant picker owns its markup; replace it (or skip it) rather than layering both
    •
